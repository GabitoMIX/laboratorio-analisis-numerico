La idea no es memorizar fórmulas, sino observar cómo el método transforma datos iniciales en una respuesta numérica verificable.

1

Explorar

2

Calcular

3

Interpretar

Cada resultado incluye una conclusión sencilla para relacionar el cálculo con el significado del método.

Módulo 1

Interpolación de Lagrange

Construye el polinomio interpolador a partir de puntos \((x_i,y_i)\) y visualiza cada base \(L_i(x)\).

\(P(x)=\sum y_iL_i(x)\)

Entrada de datos

Tip: puedes pegar datos como 1;800, 3;2310, etc.

Módulo 2

Interpolación lineal y error porcentual

Permite estimar un valor entre dos puntos y comparar contra un valor real si se conoce.

\(f(x)=f(x_0)+\frac{f(x_1)-f(x_0)}{x_1-x_0}(x-x_0)\)

Entrada de datos

Módulo 3

Método de Falsa Posición

Analiza intervalos, calcula \(x_r\), actualiza los extremos y detiene por iteraciones o por error.

\(x_r=b-\frac{f(b)(a-b)}{f(a)-f(b)}\)

Entrada de datos

Funciones permitidas: exp, sin, cos, tan, log, sqrt, abs, pi, e.

\(A^TAc=A^Ty\)

Módulo 6 · Modelación y problemas de valor inicial

Euler, Euler mejorado, Heun y Runge-Kutta

Formula y resuelve el PVI \(y'=f(x,y),\;y(x_0)=y_0\). Elige un modelo aplicado o escribe tu propia función.

\(y_{n+1}\approx y(x_n+h)\)

Define tu problema de valor inicial

Modelo de crecimiento proporcional: la tasa de cambio es proporcional a la población. y(0)=10 y k=0.5.

Usa x, y, potencias ^ y funciones como sin(x), cos(x) y exp(x). Escribe decimales con punto (0.5).

En algunos cursos, «Euler mejorado» y «Heun» son el mismo método. Aquí se diferencian como punto medio y trapecio para poder comparar ambas variantes.

¿Qué significan x, y, h y k?

x: tiempo o variable independiente. y: cantidad que cambia. h: distancia entre pasos. f: derivada o tasa de cambio. k₁…k₄: pendientes evaluadas para estimar el siguiente valor.

Módulo 7 · Convergencia y estabilidad

¿Qué cambia al reducir el tamaño del paso?

Compara los cuatro métodos con h, h/2 y h/4 y explora un criterio de estabilidad linealizada.

\(h\rightarrow0\)

Parámetros de comparación

Ejemplo clásico de estabilidad: y'=-2y, con y(0)=1. Se compara el error respecto a RK4 refinado, no respecto a una solución analítica.

Módulo 8 · Sistemas de ecuaciones ordinarias

Dos ecuaciones que evolucionan juntas

Resuelve \(y'=f(x,y,z),\;z'=g(x,y,z)\) con condiciones iniciales y pasos simultáneos.

\(\mathbf{Y}'=\mathbf{F}(x,\mathbf{Y})\)

Modelo de ejemplo: sistema acoplado

Ejemplo de oscilación: y'=z, z'=-y, y(0)=1 y z(0)=0. De forma exacta y=cos(x), z=-sin(x).

¿Por qué se hizo esta web?

Esta web se desarrolló como un apoyo didáctico para la materia de Análisis Numérico, con el fin de facilitar la comprensión de los métodos vistos en clase mediante una experiencia visual, interactiva y paso a paso.

La intención es que el estudiante no solo vea el resultado final, sino también el procedimiento: datos de entrada, fórmulas utilizadas, iteraciones, tablas y conclusiones. De este modo, el aprendizaje resulta más claro, dinámico y práctico.
