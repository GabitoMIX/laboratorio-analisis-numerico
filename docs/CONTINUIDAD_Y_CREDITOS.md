# Continuidad del proyecto y créditos

- **Proyecto anterior:** Kevin Eduardo García Moreno. Se conservaron sus calculadoras de interpolación, falsa posición, mínimos cuadrados y regresión, así como el reconocimiento a su contribución original.
- **Ampliación v2.0:** labor educativa renovada para Gabriel Argenis Medina Carrero; incluye métodos de EDO, sistemas, estabilidad y convergencia.
- **Universidad Simón Bolívar, sede Cúcuta:** contexto académico e identidad visual de referencia. Este repositorio es un **proyecto estudiantil no oficial**.
