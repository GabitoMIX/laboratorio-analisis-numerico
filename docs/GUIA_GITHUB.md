# Mantenimiento del repositorio

Repositorio: `https://github.com/GabitoMIX/laboratorio-analisis-numerico`

La importación inicial se realiza sobre la rama `main`. El repositorio permanece **privado** hasta aclarar los derechos del código anterior y el uso del logotipo universitario.

## Desarrollo local

1. Clonar el repositorio con Git o GitHub Desktop.
2. Abrir `index.html`, o iniciar `python -m http.server 8000`.
3. Ejecutar `node --test tests/edo.test.js`.
4. Revisar cada módulo y sus resultados antes de guardar cambios.

## Publicar cambios

```bash
git add .
git commit -m "Mejora verificada: describir cambio"
git push origin main
```

No se necesita backend ni base de datos. No se incluyen las fotografías del proyecto anterior ni PDFs personales en GitHub.

## Sitio público

No activar GitHub Pages público sin revisar previamente las autorizaciones del código heredado y de la imagen institucional.
